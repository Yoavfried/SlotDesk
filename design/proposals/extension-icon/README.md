# Extension icon proposals

Prepared 26 October 2026 for owner selection. **Neither option is installed.**

- [Revised A: slimmer SD](sd-slim.svg), using the larger central letters on a square header-lime background.
- [Revised B: slimmer bracketed SD](bracket-sd-slim.svg), with the logo’s bracket opacity.
- [Side-by-side size comparison](compare.html).
- [Revised comparison image](comparison-slim.png), including previous/revised samples at the same size.

Both start from the outlined VT323 glyphs in the existing [brand banner](../../assets/slotdesk-banner.svg), ink `#15160A`, background `#D8E84A`, bracket opacity 55%. On 26 October the owner requested slimmer lettering because the enlarged icon letters looked heavier than the extension wordmark. The revised vectors apply a 2-glyph-unit background stroke over each outline, reducing an approximately 8.32-unit main stem to 6.32 units without changing layout or substituting another font. These are deliberately thinned outlines, not a different VT323 font weight. Font license: [VT323](../../../extension/fonts/LICENSE-VT323.txt).

Original [SD](sd.svg), [bracketed SD](bracket-sd.svg) and [comparison](comparison.png) remain for reference. Revised PNG exports are provided at 16, 32, 48, 128 and 1024 pixels. Inspect both the browser-rendered native-size samples and raster exports before choosing an option; small-size legibility remains part of owner review.

After owner selection: prepare and inspect raster exports at required browser/store sizes, wire toolbar/extension manager/favicon references, and review store-specific listing artwork. These are not part of this implementation.
