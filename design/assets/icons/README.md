- Keep the C2 compact layout and middle-weight SD letter contours unchanged.
- Brackets use the original/bold contours, retaining 55% opacity.
- Background: `#D8E84A`; ink: `#15160A`.
- Prepared PNG sizes: [16](slotdesk-16.png), [24](slotdesk-24.png), [32](slotdesk-32.png), [48](slotdesk-48.png), [64](slotdesk-64.png), [128](slotdesk-128.png), [256](slotdesk-256.png), [512](slotdesk-512.png), [1024](slotdesk-1024.png).
