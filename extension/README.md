# SlotDesk Chrome extension

Current release: **0.8.0**. Load this `extension/` directory as an unpacked extension, or build the approved tester ZIP from the repository root:

```sh
npm run package:slotdesk
```

The ZIP includes `START-HERE.html`, local fonts, general Help and the privacy notice. Sign-in is limited to the approved Google pilot audience. Existing-event time changes and new invitations require review and explicit confirmation.

Use [installation](../docs/install.md), [product decisions](../docs/README.md) and [security/privacy](../docs/security.md) for current behavior and pending live validation.
