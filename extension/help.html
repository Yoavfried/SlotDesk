Find a time

Connect Google, save your own profile and choose a default invitation calendar. Set up familiar faces if you wish, then continue to the workspace menu and choose New meeting. Search saved profiles by name or email and add the people attending. A new email opens a short profile setup. Confirm each person’s timezone, choose dates and duration, then select Find a time. Start-time spacing in Advanced controls how often a candidate start is checked.

You take part only when your profile is included. Use Manage profiles to edit saved people. New meeting clears the title and attendee selections while keeping your saved profiles.

Existing meetings

From the workspace menu, select Existing meetings. Choose start and end dates, select one or more calendars, and adjust Times shown in if needed. SlotDesk loads all accessible calendars for those dates; adding or removing a calendar updates the list from memory. Changing the dates or selecting Refresh meetings loads the range again. View details shows guest responses, optional status and Calendar/Meet links. Created with SlotDesk identifies events whose SlotDesk metadata is available. Use Refresh meetings after a guest responds to load the latest response. Busy-only access cannot show event details; incomplete reads may omit meetings. The red Overlapping label names conflicts in the displayed calendars through expandable details. Shared copies do not conflict with themselves. Reschedule meeting opens a separate review before any time changes.

Reschedule a meeting

Open a meeting’s details and select Reschedule meeting. Search for another time or enter exact dates/times. Confirm missing guest timezones through short profile setup. Review the current and new times, guests and warnings, then select Reschedule & notify guests. The meeting details and video link are kept; a recurring change affects only this occurrence. All-day appointments keep their date-only format.

Only the organizing calendar with write access can apply a change. Other appointments are never moved automatically. A conflict proposal offers replacement times for the other meetings; confirmed conflicts remain in Appointments to reschedule until handled or dismissed.

If a change needs checking, use Review unfinished change. SlotDesk reads the same appointment before retrying. If someone else changed it during review, refresh its details instead of overwriting their edit.

Meeting alerts

The bell shows upcoming invitations where a guest answered No, with optional guests identified. Find another time opens rescheduling. Dismiss keeps the same observed response quiet. Responses update during normal calendar reads and Refresh meetings; there are no background alerts or automatic changes.

Profiles

Manage profiles has searchable saved people, Add profile and A few familiar faces? suggestions. Confirm a suggested person’s timezone before saving. Profiles are separate from the participant list of a new meeting.

Settings and appearance

Use the gear beside the logo to open Settings. Dark mode and Open full workspace are at the top. You can also change the time display, default invitation calendar and your profile. Appearance options includes Follow system.

Google connection

The email badge below the logo shows the connected Google account. The exit icon beside it disconnects that account. Use the intended Chrome profile and allow the requested calendar event, calendar list and free/busy access.

Access is blocked

Ask the app owner to add your Google email to the private pilot’s test audience and check the requested scopes. Your Workspace administrator may also need to allow SlotDesk. You do not create a Google Cloud project.

A calendar is missing

Open Google Calendar with the connected account and check sharing and the calendar list. Reconnect or search again to refresh available calendars. Only writable calendars are offered as organizing calendars.

Calendar status and participant fit

Calendar data complete means calendar data covers this time for every included participant. Calendar data incomplete means at least one person’s full calendar could not be checked, including optional guests. This is separate from whether a time fits or has conflicts, and it does not mean guests have accepted invitations.

Each participant row explains whether the time fits their calendar and profile rules. Availability unconfirmed means calendar data is missing or incomplete. A known conflict is shown even when other data is incomplete. Local times appear when their timezone differs from the proposal.

Availability is unconfirmed

Open Advanced options → Calendar data to see incomplete reads. Edit the person’s profile → Advanced → Availability calendars to check sources. A saved profile or stated availability does not give access to that person’s calendar.

Review and send

Review the title, organizing calendar, participants, full local dates/times and warnings. Everyone retained in the participant list is invited. Copy meeting details if you want to create the event manually. Create & send invitations creates a real new event and notifies its participants.

A send needs checking

Use Review unfinished send on the workspace menu. SlotDesk checks the same event identifier before retrying, including after reload. The draft stays unchanged while its outcome is uncertain. Check the selected calendar before manually creating another copy.

When creation succeeds, Meeting created appears over the workspace menu. Use Done to continue or View meeting to open its calendar list.

Google Meet is still pending

An event can be created successfully while Google prepares the video link. Open the created event or use Check video link. If Google reports a conference failure, add a link in Google Calendar.

Privacy and saved data

Saved profiles, preferences and unfinished invitation details stay in this browser. Loaded calendar data is cleared from connected SlotDesk windows when you disconnect. Invitations are sent after your review and confirmation.

Before using a work account

First test a busy test calendar with consenting participants. Verify local times, recipients, optional status and Meet against Google Calendar. Confirm workplace approval before connecting a work account. This build creates new meetings and supports reviewed individual time changes. It does not delete appointments or move them between calendars. Google’s event permission is broader than that application behavior.
