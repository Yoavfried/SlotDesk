## Added

- Add from calendar inside the trip editor, with date and calendar selection and appointment details prefilled into the flight form.
- Duplicate-flight checks for saved calendar links, shared event copies and matching routes/departures.

## Improved

- Automatic calendar matching runs on Save for flights that have not already been identified. Editing cities or departure dates/times updates estimates without reading calendars.
- Detected-flight alerts open the trip editor with available route, departure and arrival details prefilled.
- Manually selected appointments can become SlotDesk flights even when automatic Event detection is off. Missing details remain available to complete.

## Fixed

- Prevented repeated flight additions through calendar selection and detection alerts.

The Chromium ZIP is the desktop extension package. The Firefox XPI is unsigned; the Safari archive contains source only.

To update an unpacked installation, replace the files in its existing folder, reload the extension and reopen SlotDesk. Keep the existing installation to retain saved profiles and settings.
