# SlotDesk store submission kit

Prepared 26 October 2026 for Chrome Web Store, Microsoft Edge Add-ons and Firefox AMO. These are review drafts, not live listings. The installed beta remains Google-only; Outlook follows 1.0.0.

- [Listing copy](listing.md)
- [Permissions and data declarations](declarations.md)
- [Reviewer instructions](reviewer-instructions.md)
- [Owner publication steps](owner-steps.md)
- [License proposal](license-proposal.md)

Use the approved C2 icon in [the icon assets](../../design/assets/icons/README.md), the real wordmark and synthetic-data screenshots. Never upload private calendars or screenshots showing real personal data. Store screenshots must match the submitted build. Do not insert invented listing URLs or a website link in the repository.

The public support email, public privacy URL, publisher accounts/identities, Google public OAuth verification and signed/native-browser validation remain open. Final user-experience approval belongs to the owner. The partial security audit identified three issues addressed in this preparation build; it is not exhaustive security clearance. See [review evidence](../release-readiness-review.md).

## Media

`media/01-workspace.png`, `02-profiles.png` and `03-existing-meetings.png` are 1280×800 draft screenshots captured from the actual interface with synthetic calendars. `media/store-logo-128.png` and `store-logo-512.png` are unchanged copies of the approved icon. Screenshots show the preparation build and must be regenerated for the final submitted build.

Chrome accepts 1–5 screenshots at 1280×800; Edge accepts up to six, including this size. Firefox listing images can reuse the captures where the resulting Firefox UI matches. [Chrome listing guidance](https://developer.chrome.com/docs/webstore/cws-dashboard-listing), [Edge listing guidance](https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension).
