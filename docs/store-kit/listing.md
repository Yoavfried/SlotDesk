## Name

SlotDesk

## Short description

Find meeting times across timezones, check calendar conflicts, and review invitations and changes before sending.

## Full description

Good meetings start with a good time.

SlotDesk helps executive assistants plan Google Calendar meetings across people, calendars and timezones. Save a profile for each person, link the calendars that describe their availability, and find useful meeting options with clear explanations when schedules clash.

- Compare suggested times in each participant’s local timezone.
- Configure working days, convenience hours, blockers and individual meeting rules.
- Review new invitations before sending them through Google Calendar.
- View existing meetings, check guest responses, and review individual edits or rescheduling.
- See overlapping appointments and choose which meeting to reschedule.
- Plan trips and flights so availability follows changes in location and timezone.
- Back up local settings or share selected profiles using portable files.

Profiles and settings stay in your browser. Calendar reads and reviewed changes go directly to Google. A SlotDesk sign-in service exchanges and refreshes Google credentials. SlotDesk has no appointment-deletion feature; adding/removing guests and rescheduling require review. Removing a guest withdraws that guest’s invitation.

Chrome and Edge record the confirmed onboarding name, email, timezone, browser and completion time for registration analysis. In Firefox, sharing that record is optional. A separate unchecked choice controls occasional project updates. See the privacy notice for destinations, local storage, retention and removal requests.
